Principios SOLID aplicados
S
SRP
Cada clase tiene 1 sola responsabilidad. UI dibuja, Game orquesta, Validator valida.
O
OCP
Game no cambia si cambias el renderer o el validador.
L
LSP
UI implementa completamente IGameUI sin romper el contrato.
I
ISP
Interfaces pequeñas y específicas: IGameUI, IWordProvider, IWordValidator.
D
DIP
Game depende de abstracciones (interfaces), no de clases concretas.
